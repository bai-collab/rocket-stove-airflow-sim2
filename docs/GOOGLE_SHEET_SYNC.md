# Google 試算表同步設定

把多台電腦（每台都執行本機導師服務）的學習紀錄集中到老師自己的 Google 試算表，教師工作台就能看到全班資料。這個功能可以不用；沒設定時，紀錄只留在各台電腦的 `local-data/`。

## 會同步什麼

| 方向 | 內容 |
|---|---|
| 這台電腦 → 試算表 | 這台電腦產生的測試紀錄與導師提問紀錄（學生代號、時間、本課目標、爐型、測試摘要、提問與導師回覆） |
| 試算表 → 這台電腦 | 其他電腦送上去的紀錄；匯入後只用來查看與分析，**不會再送回試算表** |

- 新紀錄產生約 15 秒後會自動送出；教師頁「學生紀錄」分頁的「與試算表同步」會同時送出與匯入。
- 同一筆紀錄（相同紀錄 ID）不會重複寫入。
- API 金鑰、教師密碼不會送到試算表。

## 設定步驟（約 10 分鐘）

1. **建立試算表**：用老師自己的 Google 帳號建立一個新的 Google 試算表。
2. **貼上指令碼**：試算表選單「擴充功能 → Apps Script」，刪掉預設內容，貼上本專案 [`scripts/tutor/sheets/Code.gs`](../scripts/tutor/sheets/Code.gs) 的全部內容，按儲存。
3. **產生 RECORD_TOKEN**：在教師頁「設定」分頁按「產生一組隨機 RECORD_TOKEN」，複製產生的字串（先不要離開頁面）。
4. **設定指令碼屬性**：Apps Script 左側「專案設定（齒輪）→ 指令碼屬性 → 新增指令碼屬性」，屬性填 `RECORD_TOKEN`，值貼上第 3 步的字串。
5. **初始化並授權**：回到編輯器，上方函式選單選 `setupSheet`，按「執行」，依畫面授權（Google 會提示這是未驗證的應用程式，因為是你自己的指令碼）。完成後試算表會多一個「火箭爐學習紀錄」分頁。
6. **部署**：右上「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
   按部署，複製結尾是 `/exec` 的網址。
7. **填回教師頁**：「設定」分頁的「Google 試算表同步」填入第 6 步的網址與第 3 步的 RECORD_TOKEN，按「保存同步設定」。
8. **測試**：到「學生紀錄」分頁按「與試算表同步」，狀態列顯示「上次同步 …」即成功；有紀錄時試算表會出現新列。
9. **其他電腦**：每台執行本機服務的電腦，都在自己的教師頁填入**同一組**網址與 RECORD_TOKEN。

修改 `Code.gs` 後要「部署 → 管理部署作業 → 編輯 → 版本選新版本」，網址才會用到新程式。

## 試算表欄位

「火箭爐學習紀錄」分頁前 16 欄是給人看的（時間、學生代號、類型、本課目標、爐型、黑煙排出累積、炭保留率、持續燃燒比例、學生提問、導師回覆等），隱藏的「完整紀錄1～4」欄是同步用的原始資料，**請不要修改或刪除**；被改壞的列在匯入時會被略過。文字欄位前面有一個看不見的字元，用來避免 `=`、`+`、`@` 開頭的學生輸入被當成公式。

## 安全與隱私

- 只要同時知道 `/exec` 網址與 RECORD_TOKEN，就能讀寫這張表的紀錄；兩者都不要貼在公開地方或交給學生。懷疑外洩時：在 Apps Script 改掉 `RECORD_TOKEN`，再到每台電腦的教師頁更新。
- 網頁應用程式必須設為「所有人」才能讓本機服務呼叫，但沒有正確 RECORD_TOKEN 的請求會被拒絕。
- 本機服務只把 RECORD_TOKEN 送到 `script.google.com`；Google 回應的轉址只接受 `script.googleusercontent.com`，而且不帶 RECORD_TOKEN。
- RECORD_TOKEN 要求 16～200 個英數符號（比 teacher_UI 範本的 8 碼下限嚴格），建議直接用教師頁產生的 32 碼。
- 試算表內容受 Google 帳號與共用設定管理；不要把試算表共用給學生。

## 常見錯誤

| 教師頁顯示 | 可能原因 |
|---|---|
| 試算表拒絕了 RECORD_TOKEN | 指令碼屬性與教師頁的 RECORD_TOKEN 不同，或屬性名稱不是 `RECORD_TOKEN` |
| 沒有回傳預期資料 | 部署類型不是「網頁應用程式」、存取權不是「所有人」，或貼的不是 `/exec` 網址 |
| 試算表指令碼回報錯誤 | 沒有執行 `setupSheet`，或修改 Code.gs 後沒有部署新版本 |
| 連不到 Google 試算表 | 這台電腦無法上網，或學校網路擋住 `script.google.com` |

## 驗證範圍

自動測試在 Node 裡用模擬的 Apps Script 環境執行**同一份** `Code.gs`（含 302 轉址、兩台電腦互相同步、重送不重複、公式字元、損壞列），但沒有在真的 Google 帳號上部署過；第一次使用請依第 8 步實際確認。
